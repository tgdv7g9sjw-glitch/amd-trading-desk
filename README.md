# OIMS v1.0 Professional

Upload all files to the GitHub repository root and overwrite existing files.

Includes monthly/YTD income bars, AMD/HIMS/TSLA/NOW, purpose-based CC management, DDMMYY dates, DTE, minimal open/close workflow, and automatic journal history.

Important: do not overwrite data/positions.csv or data/journal.csv if you already entered live data. Download the journal regularly because Streamlit local CSV storage can reset.
